# Финансовая модель и план выхода на рынок для Nous Platform
## Глобальный продукт для профессионального трейдинга (крипта + традиционные рынки)

---

## 1. КЛЮЧЕВЫЕ ДОПУЩЕНИЯ (Реалистичный сценарий)

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **Рынок** | Глобальный: крипто + форекс + фондовый | Order Flow трейдеры по всему миру |
| **Целевая аудитория (TAM)** | 5-10 млн трейдеров | По данным Binance (200M+ пользователей), из них 2-5% профи |
| **Достижимая аудитория (SAM)** | 500 000 (5-10% от TAM) | Те, кто готов платить за профессиональные инструменты |
| **Конверсия в платящих** | 3-7% | Выше среднего за счет нишевости |
| **Средний чек (ARPU)** | $299/год или $39.9/мес | Конкурентно с ATAS ($500-2000) |
| **Churn rate** | 2-4% в месяц | Низкий для проф. инструментов |
| **Команда** | Удаленная, международная | Разработчики из РФ/СНГ + Европа/US для продаж |
| **Средняя зарплата** | $2000-5000/мес (в зависимости от роли) | Реалистично для найма |

## 2. ПЕРЕСМОТРЕННАЯ СТРАТЕГИЯ ВЫХОДА

**Ключевое изменение:** Live Trading с самых ранних этапов, затем маркетплейс, затем IDE.

```
Этап 1 (0-6 мес): MVP с LIVE TRADING (Binance, Bybit) + базовый UI
         ↓
Этап 2 (6-12 мес): Поддержка криптобирж + форекс/фондовые провайдеры
         ↓
Этап 3 (12-18 мес): Маркетплейс (плагины, индикаторы, стратегии)
         ↓
Этап 4 (18-24 мес): IDE + REPL + DSL (для разработчиков)
```

## 5. ТОЧКА БЕЗУБЫТОЧНОСТИ (Break-even)

**Расчет по месяцам:**

```
Месяц 0-3: Pre-seed (-$2.5k)
Месяц 4-9: Seed (-$48.8k) → Накоплено: -$51.3k
Месяц 10-18: Series A (+$89.5k) → Накоплено: +$38.2k
```

**Точка безубыточности:** **Месяц 15** (через 15 месяцев после старта разработки)  
**То есть:** через 12 месяцев после запуска MVP с live trading
