## Определение "Готово" (Definition of Done)
1. Код написан и отрефакторен
2. Проходит code review (саморецензия)
3. Проходит unit тесты (если есть)
4. Документация обновлена
5. Задача протестирована вручную
6. Код замержен в main ветку

## Git workflow
1. Создать ветку: `feature/NOUS-{id}-short-description`
2. Коммиты: `[NOUS-{id}] Краткое описание`
3. PR создается когда задача готова
4. Мерж после self-review
