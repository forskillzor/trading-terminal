# Шаблон для ежедневного стендапа

## Формат
**Время:** 10:00 (15 минут)
**Участники:** Вся команда
**Формат:** Каждый участник отвечает на 3 вопроса

## Вопросы для каждого участника

### 1. Что сделал вчера?
- Какие задачи завершил
- Какой прогресс по текущим задачам
- Какие проблемы решил

### 2. Что планирую сделать сегодня?
- Какие задачи возьму в работу
- Какие цели на день
- Какие блокирующие факторы ожидаю

### 3. Блокеры (если есть)
- Что мешает прогрессу
- Какая помощь нужна от команды
- Какие риски вижу

## Пример заполнения

### [Дата] Daily Standup - Sprint [номер], День [день]

**Участник:** skillzor (Разработчик)

**Что сделал вчера:**
- Завершил NOUS-6: Реализовал базовый DomWidget
- Начал работу над NOUS-7: DomViewModel (50% готово)
- Исправил баг с обновлением данных в реальном времени
- Провел code review для NOUS-5

**Что планирую сделать сегодня:**
- Завершить NOUS-7: DomViewModel
- Начать NOUS-8: DomSectionNinja
- Написать тесты для DomWidget
- Подготовить PR для NOUS-7

**Блокеры:**
- Нужны clarification по требованиям к DomSectionNinja
- Ожидаю feedback по PR NOUS-6

## Рекомендации
- **Будь конкретен:** Говори о конкретных задачах и их ID
- **Будь краток:** 1-2 минуты на человека
- **Фокус на блокерах:** Если есть блокеры - говори сразу
- **Обновляй YouTrack:** После стендапа обнови статусы задач
- **Записывай action items:** Если нужны действия от других

## Action Items Tracking

## Метрики дня
- **Завершено задач:** [число]
- **Новых блокеров:** [число]
- **Решено блокеров:** [число]
- **Общий прогресс спринта:** [%]

## Notes для фасилитатора
1. Начинай вовремя
2. Следи за временем (макс 15 минут)
3. Убедись, что все высказались
4. Зафиксируй блокеры и action items
5. Обнови доску YouTrack после встречи
